# Mom Boss Wellness — Marketing Site UI Kit

Interactive click-through recreation of the marketing/coaching site — the brand's primary product surface (no app or codebase was supplied, so this is an original composition using the brand's colors, type, and logo family, not a pixel port of an existing site).

Screens: **Home** (hero, program teasers, testimonial), **Programs** (tabbed program detail + book-a-call modal), **Coaches** (coach bios), **Community** (events + join form).

Built entirely from `components/` primitives (NavBar, Footer, Button, Badge, Card, Avatar, Tabs, Alert, Modal, Input, Textarea, Checkbox, Switch) — no one-off styling. Open `index.html` and click through the nav to explore.
