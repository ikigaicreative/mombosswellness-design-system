# System overview

## The five mom personas

From The Sustainability Gap white paper (`docs/research/`). Each persona has a signature icon and a set of nine icons in `personaIcons`.

| Persona | Where she is | Icon set |
| --- | --- | --- |
| The Mom Running on Empty | Still in the system, no margin left | `running-on-empty`, `moon`, `breath`, `checklist`, `boundaries`, `release`, `water`, `stillness`, `time` |
| The Mom Rebuilding | Through burnout, doing the work | `rebuilding`, `village`, `boundaries`, `plant`, `calendar`, `shield`, `journal`, `together`, `presence` |
| The Mom on Pause | Stopped on purpose | `on-pause`, `moon`, `sunrise`, `window`, `journal`, `mountain`, `leaf`, `heart`, `stillness` |
| The Mom Reinventing | Same drive, new direction | `reinventing`, `orient`, `spark`, `design`, `lightbulb`, `seedling`, `growth`, `mountain`, `focus` |
| The Mom Who Builds | Left the table and built her own | `builds`, `crown`, `growth`, `coin`, `wallet`, `shield`, `practice`, `expand`, `focus` |

## Icon realms

| Realm | Focus | Icons |
| --- | --- | --- |
| Her Season | One signature icon for each of the five mom personas | `running-on-empty`, `rebuilding`, `on-pause`, `reinventing`, `builds` |
| Mind | Clarity, focus and the mental load | `lightbulb`, `journal`, `focus`, `spark`, `checklist` |
| Heart | Emotional wellbeing and joy | `heart`, `smile`, `sunrise`, `breath`, `release`, `sun` |
| Body | Strength, rest and nourishment | `strong`, `dumbbell`, `moon`, `water`, `apple`, `pulse` |
| Money | Financial wellbeing and security | `coin`, `growth`, `wallet`, `seedling`, `shield`, `crown` |
| Home | Environment and the space around her | `house`, `leaf`, `plant`, `mountain`, `window`, `calendar` |
| Village | Relationships and community | `together`, `family`, `conversation`, `gift`, `village` |
| What Works | What the moms in the research say brings them back to themselves | `stillness`, `boundaries`, `presence`, `time` |
| The Path | The five steps of the Mom Boss Framework | `orient`, `reclaim`, `design`, `practice`, `expand` |
