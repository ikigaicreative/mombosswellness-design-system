Pill-shaped call-to-action button for primary actions across the site and app.

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Book a discovery call</Button>
```

Variants: `primary` (evergreen, default), `secondary` (plum), `gold` (crown gold, for high-visibility launch CTAs), `ghost` (transparent, hairline border), `outline` (transparent, colored border). Sizes: `sm`, `md`, `lg`. Pass `icon` for a leading icon element (e.g. a Lucide icon). `disabled` mutes to neutral gray.
